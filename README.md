# JavaScript Basic Learning

Repo học JavaScript cơ bản từ con số 0. Ghi lại kiến thức, bài tập và ghi chú cá nhân trong quá trình học.

## 📌 Mục tiêu

- Nắm vững cú pháp JS cơ bản
- Hiểu rõ các khái niệm nền tảng: biến, kiểu dữ liệu, hàm, scope, closure, async...
- Luyện tập qua bài tập nhỏ mỗi ngày
