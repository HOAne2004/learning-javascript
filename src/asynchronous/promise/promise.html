🔮 Promise trong JavaScript

Hiểu rõ 3 trạng thái & cơ chế bất đồng bộ của Promise

1. Promise là gì?

Promise là một object đại diện cho kết quả của một tác vụ bất đồng bộ — kết quả có thể chưa có ngay mà sẽ có trong tương lai.

Hãy tưởng tượng Promise như một phiếu hẹn: bạn đặt hàng online, shop đưa phiếu hẹn (Promise). Phiếu đó có thể ở 3 trạng thái:

  • ⏳ Đang xử lý → pending
  • ✅ Giao thành công → fulfilled
  • ❌ Giao thất bại / hủy đơn → rejected

2. Ba trạng thái của Promise

Trạng thái Ý nghĩa Cách chuyển
pending Đang chờ — chưa có kết quả Trạng thái ban đầu
fulfilled Thành công — có kết quả Gọi resolve(value)
rejected Thất bại — có lỗi Gọi reject(error)
⚠️ Promise chỉ chuyển trạng thái MỘT LẦN DUY NHẤT. Sau khi resolve/reject, không thể đổi lại.

3. Cú pháp tạo Promise

const p = new Promise((resolve, reject) => {
    // Executor: chạy ĐỒNG BỘ ngay khi new Promise được gọi
    if (/* thành công */) {
        resolve("Kết quả");   // → fulfilled
    } else {
        reject(new Error("Lỗi"));  // → rejected
    }
});
💡 Nhớ kỹ: Phần (resolve, reject) => {...} gọi là executor — nó chạy ĐỒNG BỘ NGAY LẬP TỨC, không phải async!

4. Cách "tiêu thụ" Promise

a) Dùng .then() / .catch() / .finally()

p
    .then(result => {
        console.log("Thành công:", result);
    })
    .catch(error => {
        console.log("Thất bại:", error);
    })
    .finally(() => {
        console.log("Luôn chạy, dù thành công hay thất bại");
    });

b) Dùng async / await (cú pháp đẹp hơn)

async function run() {
    try {
        const result = await p;
        console.log("Thành công:", result);
    } catch (error) {
        console.log("Thất bại:", error);
    }
}

5. Sync vs Async trong Promise

Phần Chạy khi nào?
Executor (resolve, reject) => {...} SYNC — ngay khi new Promise
.then() / .catch() ASYNC — sau khi promise resolve, đẩy vào microtask queue
.finally() ASYNC — sau khi then/catch chạy xong

7. Tổng kết cần nhớ

  • Promise có 3 trạng thái: pending → fulfilled / rejected.
  • Chuyển trạng thái chỉ 1 lần duy nhất, không đổi ngược.
  • Executor chạy SYNC, chỉ có .then() chạy async.
  • .then() nhận kết quả thành công, .catch() nhận lỗi, .finally() luôn chạy.
  • Microtask (Promise) ưu tiên hơn Macrotask (setTimeout).
  • async/await chỉ là cú pháp "đường" cho Promise, bản chất vẫn là Promise.
