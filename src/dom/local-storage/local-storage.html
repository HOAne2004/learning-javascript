Local Storage

Lưu trữ dữ liệu phía client — tồn tại vĩnh viễn cho đến khi bị xóa

📚 Các phương thức chính

  • setItem(key, value) — Lưu dữ liệu (value dạng string)
  • getItem(key) — Lấy dữ liệu theo key (trả về null nếu không có)
  • removeItem(key) — Xóa dữ liệu theo key
  • clear() — Xóa toàn bộ dữ liệu trong Local Storage

🧠 Lý thuyết mở rộng

  • Chỉ lưu string: số, boolean, object, array đều phải convert.
  • Object/Array → dùng JSON.stringify(obj) khi lưu.
  • String → Object → dùng JSON.parse(str) khi đọc.
  • Phạm vi: theo origin (protocol + domain + port).
  • Vĩnh viễn: khác sessionStorage (mất khi đóng tab).
  • Dung lượng: ~5MB / domain (tùy trình duyệt).
  • Đồng bộ (synchronous) → không nên lưu data quá lớn.
  • ❌ Không lưu được: function, undefined, Symbol.
  • 🔒 Không nên lưu password/token nhạy cảm!

💡 So sánh nhanh: localStorage (vĩnh viễn) | sessionStorage (theo tab) | cookie (gửi kèm request, ≤4KB)
